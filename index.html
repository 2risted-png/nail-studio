Telegram-уведомления

При новой записи клиента заявка автоматически приходит в ваш закрытый Telegram-чат

⚠️ Важно: Telegram Bot API блокирует прямые запросы из браузера (CORS). Поэтому нужен прокси-URL (например, бесплатный Cloudflare Worker — инструкция ниже). Без прокси отправка не будет работать.
Как настроить (5 минут):
  1. Получите токен у @BotFather → /newbot
  2. Добавьте бота в группу и сделайте админом. Получите chat_id через @userinfobot (для групп начинается с -)
  3. Разверните прокси: зайдите на workers.cloudflare.com → создайте Worker → вставьте код ниже → Deploy
  4. Скопируйте URL воркера (вида https://имя.ваш-аккаунт.workers.dev) и вставьте в поле «Прокси-URL»
  5. Сохраните и нажмите «Отправить тестовое сообщение»
